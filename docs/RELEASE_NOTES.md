## How to install / Telepítés

**Windows:** download `Yoinker-Windows.exe` below, double-click it. If Windows says "protected your PC": **More info → Run anyway**.
**Mac:** download `Yoinker-macOS.dmg`, drag Yoinker to Applications, then **right-click → Open** the first time.
**Linux:** download `Yoinker-Linux`, make it executable (right-click → Properties), double-click.

Step-by-step with every click: [English guide](https://github.com/danielcsirke/yoinker/blob/main/docs/GUIDE.md) · [Magyar útmutató](https://github.com/danielcsirke/yoinker/blob/main/docs/UTMUTATO.md)
